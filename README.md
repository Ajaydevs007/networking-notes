# Computer Networking Notes
Networking fundamentals studied as part of 
OCSP cybersecurity training at Offenso Academy.

## Why Networking Matters in Cybersecurity
Understanding how networks work is the foundation 
of both offensive security and SOC operations.
Every attack travels through a network. Every 
defense monitors one.
