# Computer Networking Notes

A growing set of networking fundamentals studied as part of my cybersecurity learning. Networking concepts support both offensive-security testing and SOC investigation.

## Why Networking Matters in Cybersecurity

Understanding protocols, addressing, ports, traffic flows, and network controls helps explain how systems communicate—and how analysts investigate suspicious activity.

## Topics in This Overview

| Topic | Security relevance |
|---|---|
| OSI Model | Relate network behavior to the seven conceptual layers |
| TCP/IP | Understand protocols, connection setup, and common traffic patterns |
| DNS | Name resolution, suspicious domains, and DNS tunneling concepts |
| HTTP/HTTPS | Request/response behavior and security headers |
| Ports & Services | Recognize common services and their usual ports |
| Firewalls & IDS/IPS | Understand traffic filtering and network detection/prevention |
| Wireshark | Packet inspection and display-filter practice |
| Network Attacks | Study concepts such as MITM, ARP poisoning, and SYN flooding in authorized labs |
| SOC Relevance | Connect network telemetry with investigation and detection |

> This repository currently presents these topics in its README. Additional topic-specific files will be linked here as they are documented.
